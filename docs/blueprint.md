# **App Name**: AI Chess Master

## Core Features:

- Chessboard Display: Display a standard 8x8 chessboard with black and white squares and pieces.
- Move Input: Allow users to make moves by selecting a piece and then a destination square.
- Move Validation: Validate the moves based on standard chess rules.
- AI Move Suggestions: Provide AI-powered move suggestions to the user. The AI tool should decide whether or not to provide opening strategy or a simple safe move.
- AI Opponent: Enable the AI to play against the user by making its own moves.
- Game State Management: Implement game state tracking (whose turn it is, pieces' locations).
- Move History: Display the history of moves made by both the player and the AI.

## Style Guidelines:

- Primary color: Dark gray (#333333) for chessboard squares and UI elements.
- Background color: Light gray (#E0E0E0) for a clean and modern look.
- Accent color: Blue (#2196F3) for highlighting selected pieces and available moves.
- Body and headline font: 'Inter' sans-serif for a modern and readable UI.
- Use standard chess piece icons; highlight available moves with subtle circle icons.
- Display the chessboard prominently, with move history and AI suggestions in side panels.
- Subtle animations for piece movement and highlighting.
